      Remove C2PA Metadata Online

      C2PA (Coalition for Content Provenance and Authenticity) is a standard for attaching verifiable provenance information to digital content. A C2PA manifest may describe an asset’s origin, edits or the tools involved in its creation. ImageMetaClean re-renders your image in the browser and exports a new file, so the original embedded C2PA metadata is not carried into the export.

      What happens to the image?

      The visible pixels are drawn onto a fresh canvas. The browser then encodes a new JPG, PNG or WEBP file. This removes the original file container and its embedded provenance metadata rather than editing or forging the original manifest.

      Private C2PA Metadata Cleaning

      Processing takes place locally in your browser. Your selected image is not uploaded to our servers. The tool does not alter visible pixels beyond format conversion and normal browser re-encoding.

      Important Limitations

      This process removes supported metadata attached to the file. It does not remove visible labels, invisible watermark signals or provenance information embedded directly into image pixels. It also does not certify that an image is authentic or that every proprietary marker has been removed.

      Frequently asked questions

      What metadata does ImageMetaClean remove?

      It removes metadata carried in the original file by rendering the image to a new canvas export. This can remove EXIF, XMP, IPTC and embedded C2PA or other metadata chunks, depending on the source format and browser export.

      Are my photos uploaded to a server?

      No. Image processing happens locally in your browser. The image file is not sent to ImageMetaClean servers.

      Does this remove visible watermarks?

      No. It does not erase visible text, logos, signatures or watermarks that are part of the image pixels.

      Does it remove invisible AI watermarks?

      No. It removes supported file metadata, not hidden signals encoded in image pixels or model-specific watermarking systems.

      Which image formats are supported?

      You can export JPG, PNG or WEBP. The available output format depends on browser support and the selected option.
