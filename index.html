      What Metadata Gets Removed?

      Digital images can contain more than the visible picture. They may also carry technical and descriptive information added by a camera, editing application, publishing workflow or content-authenticity system. ImageMetaClean creates a fresh image export in your browser so supported metadata from the source file is not copied into the result.

      EXIF

      EXIF can include camera and lens details, capture date, exposure settings and, when recorded, GPS coordinates. Re-exporting the image removes the original EXIF block from the new file.

      C2PA

      C2PA is a content provenance standard that can attach signed information about an image’s origin or editing history. Re-rendering creates a new image file and does not preserve the original embedded C2PA manifest.

      XMP and IPTC

      XMP and IPTC can store author, copyright, captions, keywords, editing details and other descriptive fields. These metadata blocks are not carried over to the browser-generated export.

      How Browser-Side Cleaning Works

      Your browser opens the selected image, draws its pixels onto a fresh HTML canvas and exports a new JPG, PNG or WEBP file. The export contains the rendered image rather than the original file’s metadata blocks. The image is processed locally in your browser; it is not uploaded to our server.

      What This Tool Does Not Remove or Detect

      Metadata cleaning is not the same as removing information that is visibly or invisibly encoded in the pixels. This tool does not erase visible watermarks, logos, signatures, text, steganographic payloads or invisible AI watermark signals embedded in pixel data. It also cannot guarantee removal of every proprietary marker in every possible image format. ImageMetaClean does not detect whether an image was generated by AI. It only checks for a limited set of known metadata markers; it is not an AI-image detector. Platforms such as Meta and Facebook may independently analyse uploaded images and add their own labels or assessments.

      Frequently asked questions

      What metadata does ImageMetaClean remove?

      It removes metadata carried in the original file by rendering the image to a new canvas export. This can remove EXIF, XMP, IPTC and embedded C2PA or other metadata chunks, depending on the source format and browser export.

      Are my photos uploaded to a server?

      No. Image processing happens locally in your browser. The image file is not sent to ImageMetaClean servers.

      Does this remove visible watermarks?

      No. It does not erase visible text, logos, signatures or watermarks that are part of the image pixels.

      Does it remove invisible AI watermarks?

      No. It removes supported file metadata, not hidden signals encoded in image pixels or model-specific watermarking systems.

      Which image formats are supported?

      You can export JPG, PNG or WEBP. The available output format depends on browser support and the selected option.
