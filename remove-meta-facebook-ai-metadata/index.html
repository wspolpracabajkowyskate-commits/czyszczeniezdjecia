      How AI-Related Image Metadata Works

      Image files can contain information beyond the visible pixels. EXIF may store camera settings, timestamps and GPS coordinates. IPTC can hold captions, creator details and rights information. XMP can store editing history or software identifiers. C2PA manifests can attach signed provenance information about an asset's origin and edits. Some image workflows use these file-level fields to record AI-related details, but the exact fields vary by app, export setting and file format.

      ImageMetaClean opens the selected image in your browser, draws the visible image onto a fresh canvas and exports a new JPG, PNG or WEBP file. This re-rendering creates a new file rather than copying the original metadata containers, so supported file-level EXIF, XMP, IPTC and embedded C2PA information is not carried over to the exported copy. Your image is processed locally in your browser.

      AI metadata: This removes supported AI-related information embedded in the image file. It does not remove an AI label or notice added independently by Meta or Facebook.

      Before Uploading to Meta or Facebook

      If you want to share an image without its original file-level metadata, create a clean export here and then upload that exported copy to Meta or Facebook. This only changes metadata attached to the file. It does not change the visible image content or determine how a platform will classify it.

      Important: What This Tool Cannot Remove or Detect

      ImageMetaClean does not detect whether an image was generated or edited with AI. Its metadata check is limited to a small set of known file markers and is not a reliable AI-image detector. It does not remove visible AI labels, watermarks, logos or disclosures that are part of the image pixels. It also cannot remove invisible pixel-level watermarks or steganographic information embedded in the pixels.

      Meta and Facebook may independently analyse uploaded content and may add labels, notices or assessments using their own systems. Removing file-level metadata or a C2PA manifest does not prevent platform-side evaluation, does not guarantee that a post will be treated differently and does not prove that an image is non-AI-generated.

      Frequently asked questions

      Does this remove AI labels added by Meta or Facebook?

      No. ImageMetaClean only creates a new image file without supported metadata from the source file. It cannot remove labels, notices or assessments that Meta or Facebook adds independently.

      Can Meta or Facebook still identify an AI-generated image?

      Yes. Platforms may analyse image pixels, context, account information or other signals independently. Removing file metadata does not prevent platform-side evaluation or detection.

      Does cleaning C2PA metadata prove an image is not AI-generated?

      No. Removing an embedded C2PA manifest removes that file-level provenance record from the exported copy. It does not change how the image was created or prove that it is camera-original.

      Does this tool detect whether an image was made with AI?

      No. ImageMetaClean is a metadata cleaner, not an AI-image detector. It does not determine whether an image is AI-generated; it only checks for a limited set of known metadata markers and re-exports the image.
