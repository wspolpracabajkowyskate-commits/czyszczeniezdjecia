iPhone photos may include location information when the Camera app is allowed to use Location Services. Here is how to review that setting, control location sharing and make a separate copy for sharing.

How location gets into an iPhone photo

When location access is enabled for the Camera app, iOS can attach location coordinates to photos. The Photos app can then show a map or place name for supported images. This information is part of the photo's metadata, not something visible in the picture.

Whether a particular image contains GPS information depends on device settings, permissions and the way the image was created or exported.

Review Camera location permissions

  1. Open the iPhone Settings app.
  2. Go to Privacy & Security, then Location Services.
  3. Find Camera in the app list.
  4. Choose the location access setting that matches your preference. If you do not want new photos tagged with location, set Camera location access to Never.

Menu labels and available options can vary by iOS version. Changing this setting affects future capture; it does not automatically remove GPS metadata already stored in existing photos.

Check the location on an existing photo

  1. Open the photo in the Photos app.
  2. Tap the Info button or swipe up.
  3. If location data is present, Photos may show a map or place information.

If no location appears, that does not prove the file contains no other metadata. The Photos interface is not a complete metadata inspector.

Control location when sharing

In supported iOS sharing flows, open the share options and review the Location setting before sending. You may be able to turn location information off for that share. The exact controls depend on iOS version and sharing destination. This is useful when you want to preserve the original in Photos but share a copy without location details.

Make a separate clean copy

If you want a new image file without supported metadata from the original, use a browser-based cleaner that processes locally. ImageMetaClean opens the selected image, draws it onto a fresh canvas and exports a new JPG, PNG or WebP. Supported original metadata blocks are not copied into that canvas export.

The tool does not provide a full EXIF/GPS parser and its marker scan is limited. It cannot guarantee removal of every proprietary file marker or invisible signal embedded in pixels. Keep the original if you need the original metadata, location history or image quality.

Privacy checklist before posting

  • Check whether the photo shows a home address, workplace, school or recognisable private location in the image itself.
  • Review location access for the Camera app.
  • Check sharing options before sending an original file.
  • Keep an untouched original when provenance, copyright or work records matter.
  • Remember that platforms may process uploaded images independently.
