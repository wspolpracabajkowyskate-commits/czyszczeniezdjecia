What is photo metadata?

Image metadata is information stored alongside the visual image data. Depending on the camera, phone, editing software and export process, a file may include the date and time it was captured, camera settings, device model, GPS coordinates, author details, copyright fields, software names or content provenance information.

Not every image contains every field. Messaging apps, social networks and editing tools may remove, rewrite or add metadata when they process an image.

What should you look for?

EXIF camera fields

EXIF can include camera make and model, lens details, exposure time, aperture, ISO and capture timestamp. These fields can help photographers organise and understand their work.

GPS location

Some devices can save latitude, longitude, altitude or direction in the photo file when location tagging is enabled. A GPS field may reveal where a photo was taken, but many images have no GPS data at all.

XMP and IPTC descriptions

These fields can contain creator names, captions, keywords, rights statements, copyright notices and editing information. They can be useful for professional image workflows, so consider whether you need to preserve attribution before making a cleaned copy.

Content credentials

Some files may carry C2PA content credentials or other provenance data. These are not interchangeable with ordinary camera EXIF fields and may include signed information about origin or editing history.

Ways to check metadata on common devices

Windows

  1. Right-click the image file in File Explorer.
  2. Choose Properties, then open the Details tab.
  3. Review fields such as camera, date, dimensions and location when available.

macOS

  1. Open the image in Preview.
  2. Choose Tools, then Show Inspector.
  3. Review the information tabs. The fields shown depend on the image and macOS version.

iPhone and iPad

Open a photo in the Photos app and tap the Info button or swipe up. Depending on the photo, you may see date, camera details and a location map. The Photos app view is not a complete display of every metadata block in the original file.

Online and browser-based tools

A browser-based metadata tool can provide a quick view without requiring a desktop application. Check its privacy explanation before selecting a personal photo. Some websites upload images to a server; others process them locally.

How ImageMetaClean checks a file

ImageMetaClean displays a before-and-after comparison and performs a lightweight scan for selected known markers related to C2PA, AI disclosure, EXIF, XMP, IPTC and software strings. This is a limited marker scan, not a complete metadata parser. A result marked “not found” does not prove that no metadata is present.

The cleaner then draws the image pixels onto a new browser canvas and exports a new JPG, PNG or WebP file. Supported metadata from the original file is not copied into the new canvas export. The file is processed in your browser, not uploaded to our server.

When should you keep metadata?

Metadata is not always unwanted. Photographers, publishers and businesses may need creator, copyright, licensing, caption or provenance information. Keep an untouched original when those details matter, and clean a separate copy only when you have a clear reason.

Frequently asked questions

Can I tell where every photo was taken?

No. A photo only reveals GPS coordinates if location information was recorded and retained in the file.

Does a metadata scan prove a photo is AI-generated?

No. Metadata may contain clues about software or provenance, but it cannot reliably establish whether an image was generated by AI. ImageMetaClean is not an AI detector.

Does removing EXIF change the visible picture?

The canvas export is intended to preserve the rendered image pixels, but output format and quality settings can affect compression or transparency. Keep the original if exact preservation matters.
