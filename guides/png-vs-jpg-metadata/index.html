PNG vs JPG
metadata.

JPG and PNG are different image formats, but both can carry information beyond visible pixels. Learn which metadata types may appear, why files vary and what happens when you export a fresh copy.

JPG metadata

JPEG files can contain EXIF information such as camera model, capture date, exposure settings and GPS coordinates. They may also include XMP packets, IPTC fields, embedded thumbnails, software identifiers and other application-specific information.

Metadata is stored in segments around the compressed image data. Different cameras and editing applications write different combinations of fields, and some services remove or rewrite metadata during upload or export.

PNG metadata

PNG uses a chunk-based structure. In addition to image data, a PNG file may contain text chunks, timestamps, color profile information and other ancillary chunks. Some workflows also store descriptive or application-specific data in PNG files.

EXIF support in PNG has evolved over time and depends on the software that writes and reads the file. Do not assume every PNG contains EXIF, or that every metadata viewer displays all PNG chunks.

Are metadata fields the same in both formats?

No. Some concepts, such as creator information or software history, can be represented in different ways depending on format and software. JPEG and PNG also have different internal structures. A simple text search for a metadata marker cannot replace a format-aware parser.

What happens when you convert or re-export?

Many image editors and browser tools decode an image and encode a new file. Depending on the export settings and implementation, the new file may omit metadata from the source. It may also change compression, color handling, transparency or other image characteristics.

ImageMetaClean draws the selected image into a browser canvas and exports JPG, PNG or WebP. Supported metadata from the original container is not copied into the new canvas export. This does not guarantee removal of every proprietary marker in every format, and it does not remove information embedded in the visible or invisible pixel content.

Choosing a format for a clean copy

Choose JPG

JPG is commonly used for photographs. It uses lossy compression, so repeated exports or lower quality settings can affect fine detail. It does not preserve transparent pixels.

Choose PNG

PNG is useful for graphics, screenshots and images that need transparency. It generally uses lossless compression, but files can be larger than comparable JPG photographs.

Choose WebP

WebP supports lossy and lossless image compression and can support transparency. Browser support for export is widespread but can vary in older environments.

Keep the original when metadata matters

Creator, copyright, licensing, caption and provenance information may be important for professional publishing and record keeping. Keep an untouched original and create a separate clean copy only when appropriate.
